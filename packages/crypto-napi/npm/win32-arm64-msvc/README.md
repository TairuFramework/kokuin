# @kokuin/crypto-napi-win32-arm64-msvc

Prebuilt Node-API binary of [`@kokuin/crypto-napi`](https://www.npmjs.com/package/@kokuin/crypto-napi) for win32-arm64-msvc.
Install `@kokuin/crypto-napi` instead: it selects this package through `optionalDependencies`.

GitHub build attestations record the workflow run that built each binary:
`gh attestation verify kokuin-crypto-napi.win32-arm64-msvc.node --repo TairuFramework/kokuin`.
