# @kokuin/crypto-napi-linux-x64-musl

Prebuilt Node-API binary of [`@kokuin/crypto-napi`](https://www.npmjs.com/package/@kokuin/crypto-napi) for linux-x64-musl.
Install `@kokuin/crypto-napi` instead: it selects this package through `optionalDependencies`.

GitHub build attestations record the workflow run that built each binary:
`gh attestation verify kokuin-crypto-napi.linux-x64-musl.node --repo TairuFramework/kokuin`.
