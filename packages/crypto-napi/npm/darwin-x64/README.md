# @kokuin/crypto-napi-darwin-x64

Prebuilt Node-API binary of [`@kokuin/crypto-napi`](https://www.npmjs.com/package/@kokuin/crypto-napi) for darwin-x64.
Install `@kokuin/crypto-napi` instead: it selects this package through `optionalDependencies`.

GitHub build attestations record the workflow run that built each binary:
`gh attestation verify kokuin-crypto-napi.darwin-x64.node --repo TairuFramework/kokuin`.
